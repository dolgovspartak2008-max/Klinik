# Физиотера (Уфа) — сайт

Одностраничный сайт клиники «Физиотера», Уфа, ул. Энтузиастов, 16: акция «бесплатная консультация и процедура»,
услуги и цены, с чем помогаем, о центре, контакты и форма заявки.

Другие версии сохранены в ветках:
- `archive/salavat` — сайт Центра здоровья в Салавате;
- `archive/salavat-ufa` — самая первая версия (Салават + Уфа на одном сайте).

Чистый HTML/CSS/JS без сборки + одна серверная функция для заявок (`api/lead.js`).

## Структура

```
index.html            — вся страница
politika.html         — политика конфиденциальности (152-ФЗ)
uslugi/<slug>/index.html — страницы услуг (СГЕНЕРИРОВАНЫ, руками не править — см. «SEO» ниже)
usluga.html           — старый адрес услуги (?s=id): пересылает на uslugi/<slug>/ (генерируется)
404.html              — страница «не найдено»
robots.txt, sitemap.xml — для поисковиков (sitemap генерируется)
vercel.json           — 301-редиректы и заголовки для Vercel (генерируется)
tools/build-seo.js    — генератор страниц услуг, sitemap.xml, usluga.html и vercel.json
assets/css/style.css  — стили (белый + индиго, акцент — бирюзовый из логотипа)
assets/js/config.js   — КОНТАКТЫ и настройки заявок
assets/js/main.js     — интро, меню, фильтр услуг, окна записи, «Подробнее» и Instagram, отправка формы
assets/js/services-info.js — тексты описаний услуг (окно «Подробнее»)
favicon.ico           — иконка сайта для поисковиков (16–64 px)
assets/img/           — логотип (logo.png), иконки (favicon.png 96px, apple-touch-icon.png, icon-512.png — бирюзовая «аватарка») и фото (hero, promo, svc-*, case-*, center)
assets/video/laser.mp4 — видео лазерной процедуры (карточка «Здоровые суставы»)
assets/video/priem.mp4 — видео «Что взять с собой на приём» (блок после первого экрана)
assets/img/team/      — фото специалистов; assets/img/logo-mark.svg — логотип (вектор); og.jpg — картинка для превью ссылки
api/lead.js           — приём заявок → WhatsApp (GREEN-API) и/или Telegram
```

## Контакты

`assets/js/config.js`. Пустое поле — кнопка помечается «скоро» и никуда не ведёт.
Реквизиты для политики конфиденциальности — `SITE_LEGAL` в том же файле (название, ИНН, ОГРН, e-mail).
Instagram на сайте — одна кнопка; при нажатии пациент выбирает «Клиника» (`instagram`) или «Врач» (`instagramDoctor`).

## Заявки

**Сейчас (сайт с личным кабинетом):** заявка уходит в Telegram-бот клиники только администраторам
из `app.admin_telegram_ids` (каждый должен один раз написать боту `/start`), затем пациента переводит
в WhatsApp на номер `SITE_LEADS.whatsapp` с готовым текстом заявки. Если бот недоступен — пациент всё равно
попадает в WhatsApp, заявка не теряется. Лимиты: 5 заявок с IP за 10 минут, 3 в час на один номер.

Ниже — старый способ (`api/lead.js`), он используется, только если личный кабинет отключён.

Форма есть в блоке акции и в окне «Записаться».

**Без настройки** (или на GitHub Pages) — у пациента открывается WhatsApp с готовым текстом заявки
на номер `SITE_LEADS.whatsapp`, ему остаётся нажать «Отправить».

**Автоотправка** (сайт на Vercel): Vercel → Project → Settings → Environment Variables, затем Redeploy.

WhatsApp через [GREEN-API](https://green-api.com):
1. Зарегистрироваться, создать инстанс, отсканировать QR телефоном, с которого будут уходить заявки
   (лучше отдельный номер, не тот, на который они приходят).
2. Добавить переменные:
   - `GREEN_API_ID` — idInstance
   - `GREEN_API_TOKEN` — apiTokenInstance
   - `GREEN_API_URL` — apiUrl из кабинета (если отличается от https://api.green-api.com)
   - `WHATSAPP_TO` — куда присылать заявки, только цифры, напр. `79876000037`

Telegram (можно вместе с WhatsApp — заявка уйдёт в оба):
1. Создать бота у @BotFather → токен.
2. Написать боту любое сообщение, открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` → взять `chat.id`.
3. Переменные `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

Если автоотправка не сработала, пациенту всё равно предлагается отправить заявку через WhatsApp.

## SEO

Основной домен — **https://www.fiziotera.online** (прописан в canonical, Open Graph, sitemap и в `tools/build-seo.js`).
Технический адрес `clinic-alpha-one.vercel.app` отдаёт 301 на основной домен (правило в `vercel.json`).

Тексты и цены услуг живут в `assets/js/services-info.js`. После любой правки там выполните:

```
node tools/build-seo.js
```

Скрипт пересоздаст `uslugi/*/index.html`, `sitemap.xml`, `usluga.html` и `vercel.json` — закоммитьте их вместе с правкой.
Цены на карточках главной (`index.html`) по-прежнему правятся вручную.

`slug` услуги — это её адрес (`/uslugi/<slug>/`). Не меняйте его без нужды: если всё же поменяли,
добавьте 301-редирект со старого адреса в `tools/build-seo.js` (функция `vercelConfig`).

## Личный кабинет, промокоды и Telegram-бот

Регистрация (email или Telegram), личный кабинет `/kabinet/`, приветственный бонус, реферальные промокоды,
админ-панель `/admin/` и служебный Telegram-бот. Данные — в Supabase.

```
kabinet/index.html, assets/js/kabinet.js   — личный кабинет
admin/index.html, assets/js/admin.js       — админ-панель (доступ: Telegram ID из app.admin_telegram_ids)
assets/js/sb.js                            — мини-клиент Supabase (без внешних библиотек)
assets/js/account.js                       — окно входа/регистрации, кнопка в шапке, блок «Подарок за регистрацию»
assets/css/account.css                     — стили кабинета и админки
supabase/migrations/*.sql                  — таблицы, проверки, защита от накруток, фоновые задачи
supabase/functions/account                 — регистрация, вход, вход через Telegram, восстановление пароля
supabase/functions/tg-bot                  — вебхук бота, уведомления администраторам, команды
```

**Как устроена защита.** Таблицы лежат в схеме `app`, закрытой от API; RLS включён без разрешающих политик.
Сайт вызывает только функции `public.*`, каждая сама проверяет пользователя, статус и права. Размер скидки,
владелец промокода и статусы бонусов из браузера изменить нельзя. «Один клиент — один подарок» проверяется
по телефону (таблица `app.bonus_claims` не очищается при удалении аккаунта). Скидка считается использованной
только после подтверждения администратором на приёме (в админке или кнопкой в боте).

**Email и коды.** Регистрация по email: аккаунт создаётся неподтверждённым, на почту уходит код (8 цифр, Supabase Auth);
войти можно только после ввода кода. «Забыли пароль?» — код на почту и в Telegram, затем новый пароль (остальные сеансы завершаются).
Защита от спама: ловушка для ботов, лимиты по IP и по адресу, письмо не чаще раза в минуту и не больше 5 в час на адрес,
не больше 6 попыток ввода кода за 15 минут (дальше — уведомление администраторам), одинаковые ответы для существующих и несуществующих адресов.
Рекомендуется в Supabase → Authentication → Sign In / Providers выключить «Allow new users to sign up»:
сайт создаёт пользователей только через серверную функцию, а прямая регистрация через API тогда закрыта.

**Промокод друга** засчитывается всегда (и при регистрации через Telegram — поле над кнопкой на вкладке «Регистрация»),
а скидки начисляются, только когда программа и правила включены в админке.

**Вход через Telegram.** Кнопка на сайте открывает бота с одноразовой ссылкой; пользователь нажимает
«Подтвердить» и сверяет 4-значный код. Telegram ID приходит от серверов Telegram через вебхук с секретом,
поэтому подделать его нельзя. Отдельной настройки домена в @BotFather не требуется.

**Подключение (делается один раз).**
1. Применить миграции из `supabase/migrations` по порядку.
2. Положить секреты в Supabase Vault (`select vault.create_secret('<значение>', '<имя>')`):
   `telegram_bot_token`, `telegram_webhook` (случайная строка), `internal_secret` (случайная строка),
   `ip_salt` (случайная строка), `functions_url` = `https://<ref>.supabase.co/functions/v1`.
   Почта (коды подтверждения, «Забыли пароль?», привязка email): `smtp_pass` — пароль приложения Google
   для fizioteraufa@gmail.com (myaccount.google.com/apppasswords, нужна двухэтапная аутентификация);
   при другом ящике — ещё `smtp_user`. Запасной вариант — `resend_api_key` и `mail_from`.
   Пока почта не настроена, регистрация по email проходит без кода, а код для нового пароля приходит только в Telegram.
3. Задеплоить функции `account` и `tg-bot` с выключенной проверкой JWT (`verify_jwt = false`).
4. Зарегистрировать вебхук: `select app.call_bot('setup');`
5. В `tools/build-seo.js` указать `SUPABASE_REF`, выполнить `node tools/build-seo.js`
   (появится прокси `/sb/` в `vercel.json`), в `assets/js/config.js` — `SITE_ACCOUNT.anonKey`.
6. Администраторам написать боту `/start`, войти на сайте через Telegram и в «Админ-панели → Условия»
   задать размеры скидок и включить программу. По умолчанию все скидки выключены.

`vercel.json` теперь содержит заголовки безопасности (CSP с хешами встроенных скриптов, HSTS, запрет фреймов).
Если меняете встроенный `<script>` в любой странице — перезапустите `node tools/build-seo.js`, иначе браузер его заблокирует.
