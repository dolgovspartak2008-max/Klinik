# Центр здоровья — сайт

Одностраничный сайт для пациентов: Центр здоровья (Салават) и Клиника лечения и реабилитации (Уфа).
Услуги, примеры лечения, наши центры и быстрые контакты (телефон, WhatsApp, Telegram, VK, Instagram, MAX).

Чистый HTML/CSS/JS — без сборки и зависимостей.

## Структура

```
index.html            — вся страница
assets/css/style.css  — стили (белый + индиго), анимации, адаптив
assets/js/config.js   — КОНТАКТЫ: телефон, ссылки, адреса
assets/js/main.js     — вступительная анимация, меню, слайдер, окно записи
assets/img/           — изображения
```

## Как поменять контакты

Откройте `assets/js/config.js` и впишите значения. Пустое поле — кнопка помечается «скоро»
и никуда не ведёт (в окне записи такой вариант просто скрывается).
Сейчас не заполнены: Telegram, MAX, адреса и ссылки на карты для Салавата и Уфы.

## Фотографии

Фото в `assets/img/` временно вырезаны из макета-образца и имеют низкое разрешение.
Замените их на реальные фотографии клиник под теми же именами
(`hero.jpg`, `case-*.jpg`, `center-salavat.jpg`, `center-ufa.jpg`) — ширина от 1200 px.

## Локальный просмотр

```
python3 -m http.server 8000
```
и откройте http://localhost:8000

## Публикация

- **Vercel**: New Project → импорт этого репозитория → Framework: *Other*, без команды сборки → Deploy.
- **GitHub Pages**: Settings → Pages → Deploy from branch → `main` / root.
